Text-to-Speech API

A simple HTTP API for synthesizing speech from text. CPU-only inference, no GPU required. Requires an API key — contact the maintainer to get one.

Quick example

curl -X POST https://your-deployment-url/api/speak \
  -H "Content-Type: application/json" \
  -H "X-API-Key: your-api-key" \
  -d '{"text": "Hello world", "voice": "en_US-amy-medium", "speed": 1.0}' \
  --output speech.wav

Endpoints

POST /api/speak

Synthesize text into a WAV audio file.

Headers:

HeaderRequiredDescription
X-API-KeyyesYour API key.

Request body (JSON):

FieldTypeRequiredDescription
textstringyesThe text to synthesize.
voicestringnoVoice ID (default: en_US-amy-medium). See /api/voices.
speedfloatnoSpeed multiplier 0.5 to 2.0 (default 1.0).

Response: audio/wav binary stream.

Errors: 401 for a missing/invalid API key, 400 for empty text or unknown voice.

GET /api/voices

List all configured voices and which ones are currently installed.

{
  "default": "en_US-amy-medium",
  "voices": [
    {"id": "en_US-amy-medium", "name": "Amy - English (US Female)", "available": true},
    ...
  ]
}

GET /api/stats

In-memory usage stats since the server last started.

{"requests": 42, "by_voice": {"en_US-amy-medium": 30, "es_ES-davefx-medium": 12}, "started_at": "..."}

Code examples

Python

import requests

response = requests.post(
    "https://your-deployment-url/api/speak",
    headers={"X-API-Key": "your-api-key"},
    json={"text": "Hello world", "voice": "en_US-amy-medium", "speed": 1.0},
)
with open("speech.wav", "wb") as f:
    f.write(response.content)

JavaScript

const res = await fetch("/api/speak", {
  method: "POST",
  headers: { "Content-Type": "application/json", "X-API-Key": "your-api-key" },
  body: JSON.stringify({ text: "Hello world", voice: "en_US-amy-medium", speed: 1.0 }),
});
const blob = await res.blob();
new Audio(URL.createObjectURL(blob)).play();

Notes

  • Requires an X-API-Key header. Rate-limited to 30 requests/minute per API key's caller IP.
  • First request to each new voice loads the model from disk (~1-2 seconds). Subsequent requests are fast.
  • Source: github.com/salokhiddin005/Text-To-Speech
